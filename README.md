Mathematical Card Tricks Simulation

In this project, I developed a Python-based simulation to demonstrate the mathematical logic behind card tricks, inspired by Martin Gardner's "Mathematics, Magic and Mystery." I created a Python library for card-related functions and implemented two renowned card tricks utilizing the Chinese Remainder Theorem and basic algebra. This project showcases the hidden math behind card tricks, making them intuitive and educational, and is ideal for programming assignments.


# 🎴 Card Tricks – Interactive Python Game

An interactive **card trick visualization game** built with **Python**, **PyDealer**, and **Pygame**.  
This project simulates a classic card trick with **dynamic animations, keyboard controls, and visual effects**, making it engaging and fun to explore.

---

## ✨ Features
- 🃏 **52-card deck management** using [PyDealer](https://pydealer.readthedocs.io/)  
- 🎮 **Keyboard-controlled interactions**:
  - `Enter` → Start the trick (show selected 10 cards)  
  - `Ctrl` → Continue the trick with card arrangement  
  - `Left/Right` → Rotate and shift cards dynamically  
  - `Space` → Remove top cards with animations  
  - `Q` → Exit game  
- 🎨 **Animated card movements & smooth rendering** using Pygame  
- 📐 Modular design (`CardSet`, `Settings`, `CardGame`) for easy scalability  
- 🖼️ On-screen instructions to guide the user step-by-step  

---
